# DriveWake

DriveWake is a desktop app that watches your face through the webcam and alerts you immediately when your eyes appear closed for a sustained period, which can indicate drowsiness or sleep.

## Requirements:
- Windows
- Python 3.10+
- Webcam

## Install:
1. Open the DriveWake folder.
2. Run run.bat.

This will install the required packages and launch the app.

## How it works:
- Uses your webcam to detect a face.
- Tracks the eyes.
- If eyes stay closed long enough, the app plays an alarm sound.
- Displays your current location based on browser geolocation or IP-based lookup.
- WakeMate can speak prompts and say hello using browser speech synthesis.
- Connects to a Bluetooth heart-rate watch or monitor to display live pulse data in the browser.
- Connects to a Bluetooth watch or heart-rate monitor to show live pulse readings.
